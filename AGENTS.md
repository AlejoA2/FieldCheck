# Project Instructions

## Objetivo

Construir una aplicación web y móvil preparada para producción.

## Reglas

- No modificar código sin entender primero su contexto.
- Mantener arquitectura modular.
- Evitar duplicación.
- No introducir dependencias innecesarias.
- No almacenar secretos en el repositorio.
- Toda funcionalidad debe tener criterios de aceptación.
- Toda funcionalidad importante debe tener tests.
- Ejecutar validaciones después de cambios importantes.
- Mantener documentación actualizada.

## Calidad

Antes de considerar una funcionalidad terminada:

1. Implementar.
2. Ejecutar tests.
3. Verificar compilación.
4. Revisar errores.
5. Ejecutar QA.
6. Revisar seguridad cuando corresponda.

## Git

Crear commits pequeños y descriptivos.

No realizar cambios destructivos sin confirmación.
